Como Publicar no GitHub Pages

  1. No GitHub, crie um novo repositório público (ex: atas-privadas).
  2. Faça o upload deste arquivo salvo como index.html.
  3. Vá em Settings > Pages.
  4. Em Branch, escolha main / root e salve.
  5. O link do site estará disponível gratuitamente em poucos instantes!
