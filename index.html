Como Funciona o Gravador Contínuo

1. Gravador Contínuo (Keep-Alive): O sistema foi projetado para não interromper a gravação quando houver momentos de silêncio ou pausas. Se o navegador tentar parar o microfone, o aplicativo o reconecta automaticamente em milissegundos.

2. Pontuação por Pausa: Pausas curtas de silêncio (1 a 2.5s) inserem uma vírgula no texto. Pausas mais longas (>2.5s) inserem um ponto final e iniciam a frase seguinte com letra maiúscula.

3. Upload de Áudio: Caso já possua o arquivo gravado previamente, utilize a opção "Upload de Arquivo de Áudio" para tocá-lo no navegador.

4. Privacidade Absoluta: Seus dados não passam por nenhum servidor intermediário. O botão "Destruir Dados Agora" limpa instantaneamente toda a memória RAM.
